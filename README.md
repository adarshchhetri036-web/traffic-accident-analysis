# Predictive Traffic Accident Analysis Using CCTV & Weather Data

## 📌 Overview
This project predicts traffic accident risk using large-scale CCTV-derived traffic data and weather conditions such as rainfall and visibility.

## 📁 Files Included
- Traffic_Accident_Analysis.ipynb — Main notebook
- weather_data_large.csv — Weather dataset
- traffic_data_large.csv — Traffic dataset

## ▶ Try It Out
Upload the notebook to Google Colab or run it inside Jupyter Notebook.

## 🛠 Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, OpenCV, Jupyter Notebook
